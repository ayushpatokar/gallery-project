# 📸 Gallery Project

A modern and responsive image gallery web application built using **React.js** and **Tailwind CSS**. This project allows users to browse beautiful images in a clean grid layout with a smooth and user-friendly interface and Basic Pagination Features.

## 🚀 Features

* Responsive image gallery layout
* Modern UI with Tailwind CSS
* Fast performance with React and Vite
* Dynamic image rendering
* Mobile-friendly design
* Pagination Capabality

## 🛠️ Tech Stack

* React.js
* Vite
* Tailwind CSS
* JavaScript (ES6+)

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/ayushpatokar/gallery-project.git
```

2. Navigate to the project directory:

```bash
cd gallery-project
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open your browser and visit:

```bash
http://localhost:5173
```
